# Memory candidates

Proposed notes for the human to confirm before `mem` exists. One title, tags, scope, two-line reason per line, per the note format in `intent.md` Memory.

- **Function hooks are gated server-side** — tags: function-hooks, claude-code, plugin | scope: global. Client presence (2.1.257) does not mean modules load: `tengu_plugin_hooks_modules` is a rollout flag with no local override. Check with `claude plugin validate --strict <dir>` for syntax, then a live session for whether tools actually register.
- **Manifest-driven plugin API: validate first** — tags: plugin-development, testing | scope: global. `claude plugin validate` is a fast offline loop for mapping an unfamiliar manifest-driven API. One-line throwaway modules per hook event, a second each, catch syntax and unknown-event errors before any live session.
- **macOS has no `timeout`** — tags: macos, shell, tooling | scope: global. Scripts written against GNU coreutils assume `timeout <n> <cmd>` exists and hang instead of failing fast on macOS. Use the background-and-kill pattern: run in background, wait, then kill if still alive.
- **Bun cold starts are slow under `/var/folders`** — tags: bun, performance, testing | scope: global. A `bun` process under the macOS temp mount took roughly 8s per cold start in one timing test, the same script under `/tmp` was fast. Put fixture repos and scratch dirs in `/tmp`, not the default `mktemp` location.
- **Warp tab configs carry no env** — tags: warp, tab-config | scope: global. The tab config TOML has no key for environment variables, only `directory` and `commands`. Anything a spawned session needs, like `FACTORY_MISSION`, must be inlined into the command line itself.
- **User-level permission deny outranks preset allow** — tags: claude-code, permissions | scope: global. A `deny` in `~/.claude/settings.json` blocks a tool even when a preset's `--settings` overlay allows it, the user-level file wins. A preset cannot re-enable a tool the user denied globally, only the human can.
- **Workers stall on long shell commands** — tags: worker-prompt, workflow | scope: project (Factory). Left unbounded, a worker or gatekeeper probes a system by hand with dozens of cold CLI invocations instead of writing one scripted walk. Cap probe count or wall time in the Worker prompt and push toward a fixture script.
- **Empty mission branches close without a merge commit** — tags: git, mission, factory | scope: project (Factory). `git branch --merged` reports a branch with no new commits as already merged, so `mission close` on an empty branch produces no merge commit even though the mission ran. A smoke test needs a real change to exercise the merge path.
- **Factory naming and folder conventions are load-bearing** — tags: factory, naming, terminology | scope: project (Factory). Every agent and doc must pull names from `docs/terminology.md`, never invent a synonym. Folder shape (`.factory/missions/<date>-<name>/`, `parts/<name>/part.yaml`) is resolved by convention, not config.
- **SubagentStop handoff capture is last-writer-wins per step** — tags: hooks, handoffs, factory | scope: project (Factory). When an Investigator or other sub-agent runs mid-`implement`, its final message overwrites the Worker's `handoffs/implement.md` because the hook keys on step name only. Handoff filenames need the agent role, not just the step.
